# CustomSpeed for Udemy Extension

Struggling with slow videos? Easily control Udemy speed to reduce wasted time and learn smarter at your own pace.

## Features

- Set playback speed from 0.5x to 4.0x (with 0.01 steps)
- Keyboard shortcuts (`Alt+Up`/`Down`) to adjust speed instantly
- UI slider embedded in Udemy’s speed menu
- Remembers your speed for each course
- Works on all Udemy video pages

## Installation

1. Download the extension from [AMO](https://addons.mozilla.org/en-US/firefox/addon/customspeed-for-udemy/).
2. Open any Udemy course video.
3. Click the speed menu to use the slider, or use `Alt+Up`/`Down` to adjust speed.

## Usage

1. Open any Udemy course video and click the playback speed menu to reveal the slider.
2. Use the slider to select your desired playback speed between 0.5x and 4.0x.
3. Alternatively, adjust the speed with keyboard shortcuts
   - `Alt+Up`: Increase playback speed
   - `Alt+Down`: Decrease playback speed

The slider and Udemy’s native speed selector stay in sync automatically — changing one updates the other.
